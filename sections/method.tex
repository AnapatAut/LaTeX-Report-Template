\subsection{Key Rule or Formula}

Define any formula in words, then display it. For two inputs $a$ and $b$
with weights $w_a$ and $w_b$, the combined value $c$ is
\begin{equation}
  c = \frac{w_a\, a + w_b\, b}{w_a + w_b}.
  \label{eq:combine}
\end{equation}
\Cref{eq:combine} places $c$ closer to the input with the larger weight.
